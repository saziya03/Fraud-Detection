# Fraud Detection

## 📌 Project Overview

This project focuses on analyzing transaction data to identify fraudulent and genuine transactions using Python-based data analysis and visualization.

## 🎯 Objectives

* Analyze transaction data to understand fraud patterns.
* Identify fraudulent and genuine transactions.
* Explore fraud across transaction types, amounts, banks, devices, and networks.
* Visualize key findings to support better understanding of transaction fraud.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib

## 🔍 Project Workflow

1. Load the transaction dataset.
2. Check data types, missing values, and duplicate records.
3. Perform data cleaning and exploratory data analysis (EDA).
4. Analyze fraud counts and fraud rates across transaction categories.
5. Create visualizations to communicate key findings.

## 📊 Key Findings

* Total transactions analyzed: **250,000**
* Fraudulent transactions: **480**
* Genuine transactions: **249,520**
* Overall fraud rate: **0.192%**

## 💡 Conclusion

This project demonstrates how Python libraries can be used to analyze transaction data, explore fraud patterns, and visualize findings. It provides insights into transaction behavior and helps identify categories that may require further investigation.
